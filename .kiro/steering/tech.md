# Tech Stack & Build System

## Stack

| Layer | Technology |
|-------|-----------|
| Markup | Plain HTML (multipage, one `.html` file per page) |
| Styling | Bootstrap 5.3.3 (CDN) + custom CSS (`css/styles.css`) |
| JavaScript | Vanilla ES modules (`js/main.js`, `js/site-chrome.js`) |
| Font | Manrope (Google Fonts CDN) |
| Build tool | Vite 8 |
| Package manager | npm |
| Runtime | Node.js (no server-side logic; static output only) |

## Dependencies

- **Dev only**: `vite` — no production npm dependencies exist.
- Bootstrap and Google Fonts are loaded via CDN, not bundled.

## Common Commands

```bash
# Install dependencies
npm install

# Start local dev server (hot reload)
npm run dev

# Production build (outputs to dist/)
npm run build

# Preview the production build locally
npm run preview
```

## Build Configuration

Vite is configured in `vite.config.ts` as a multi-page app with explicit `rollupOptions.input` entries for every HTML page. When adding a new page, register it in the `input` object.

## Notes

- `dist/` is git-ignored and generated by `npm run build`.
- No test framework is currently set up.
- No linter or formatter is configured.
- The project uses `"type": "module"` in package.json (ES module imports throughout).
