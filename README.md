# American Football Elite Development Ltd (AFEDEV)

Static marketing website built with **HTML**, **Bootstrap 5 (CDN)**, **custom CSS**, and **vanilla JavaScript**.

## Tech stack

- HTML: multipage site (see sitemap below)
- Styling: Bootstrap 5 + `css/styles.css`
- JavaScript: `js/main.js`, `js/site-chrome.js` (shared nav/footer)
- Dev server / build: Vite

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- `dist/` is intentionally not tracked (it is generated by Vite and ignored via `.gitignore`).
